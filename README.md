# 내 교구 뼈대 (UNO Q · App Lab)

버튼 4개 + 조이스틱 + 노트북 화면 + 영수증 프린터.
처음 열면 **배선 점검판** — 꽂은 것을 눌러 화면 칸이 켜지는지 확인. 이 위에 내 교구를 만듭니다.

## 배선 (스위치 한쪽 = 핀, 다른 쪽 = GND · 저항 없음)

| 부품 | 핀 | 선 색 |
|---|---|---|
| 버튼 A | D2 | 빨강 |
| 버튼 B | D3 | 노랑 |
| 버튼 C | D4 | 초록 |
| 버튼 D | D5 | 파랑 |
| 조이스틱 ↑ | D13 | 하네스 색 |
| 조이스틱 ↓ | D11 | 하네스 색 |
| 조이스틱 ← | D12 | 하네스 색 |
| 조이스틱 → | D10 | 하네스 색 |
| 버튼 GND 4개 | 데이지체인 → 전원 줄 GND | 검정 |
| 조이스틱 GND | 13번 옆 GND | 검정 |

- **5V · 3.3V 핀에는 아무것도 꽂지 않기**
- 프린터: USB 케이블로 허브 USB-A 포트에, 전원은 프린터 어댑터로

## 처음 올릴 때
1. App Lab → 새 앱 → 이 폴더의 파일을 같은 이름·같은 위치로 넣기 (`app.yaml`, `sketch/`, `python/`, `assets/`)
2. 실행 → 노트북 브라우저에서 `http://보드IP:7000`
3. 왼쪽 위 **● 보드 연결됨** → 화면 연결 OK

## 점검 순서 (한 개씩)
1. **화면만** — 키보드로: 방향키 = 조이스틱, 1 2 3 4 = A B C D → 칸이 켜지면 OK
2. **버튼 하나** — A만 꽂고 눌러 보기 → A 칸에 초록 테두리
3. **나머지** — 하나 꽂고 누르고, 하나 꽂고 누르고. 8 / 8 이 되면 소리
4. **프린터** — 화면의 **인쇄 시험** 버튼 → "인쇄 시험 / OK / QR" 영수증
   - 또는 브라우저에서 `http://보드IP:7000/print_test`
   - "인쇄 실패 — ○○" 가 나오면 그 이유 확인
   - USB로 안 되면 프린터를 랜선으로 허브에 꽂고 `python/printer.py` 의 `PRINTER_IP` 에 프린터 IP (9100 포트)

## 내 교구 만들기
- `PROMPT.md` 의 글을 Claude에게 붙여 넣고 [ ] 칸 채우기
- 받은 `app.js`(필요하면 `index.html`)를 **통째로** 바꿔 넣고 다시 실행

## 파일
| 파일 | 역할 | 고치나? |
|---|---|---|
| `assets/app.js` | 화면 규칙 — onKey, print | ★ 여기 |

| `sketch/sketch.ino` | 버튼·조이스틱 읽기 | 아니요 |

| `python/printer.py` | 영수증 그림 만들기 + 인쇄 | 아니요 |
| `python/fonts/` | 나눔고딕 (SIL OFL) | 아니요 |
