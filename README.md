# 도형의 이동 · 평면 우봉고 — 휴대폰 버전

경남수학문화관 체험탐구관 · 초등 4학년 수학 「평면도형의 이동」 연계

조이스틱 없이 휴대폰 화면 버튼으로 하는 평면 우봉고입니다. 교과에서 배우는 **밀기 · 돌리기 · 뒤집기**를 먼저 알아보고, 우봉고 조각으로 퍼즐에 도전합니다.

- 게임 주소: https://kkwwmm0829-design.github.io/ubongo-uno-q/
- `평면우봉고_휴대폰_QR.png` : 위 게임 주소로 연결되는 QR코드
- `index.html` 한 파일로 동작합니다. 휴대폰·태블릿·컴퓨터 브라우저에서 열면 됩니다.

## 앱 구성

첫 화면에는 버튼이 두 개 있습니다.

### A. 도형의 이동 알아보기

| 메뉴 | 하는 일 |
|---|---|
| 밀기 | ▲▼◀▶로 조각을 밀어 점선 자리에 넣는 미션 3개 → "밀었을 때 달라지는 것은?" 퀴즈. 밀어도 모양·방향은 그대로이고 위치만 바뀜을 확인 |
| 돌리기 | 조각 하나(ㄴ자·P자·N자)를 골라 퀴즈 5문제: 밀었을 때, 시계 방향 90°·180°·270°·360° 돌렸을 때의 모양 고르기. 답한 뒤 **돌려서 확인**으로 조각이 실제로 돌아가는 모습을 봄 |
| 뒤집기 | 퀴즈 5문제: 오른쪽·아래쪽·왼쪽으로 뒤집기, 오른쪽으로 두 번, 오른쪽+아래쪽으로 뒤집기. **뒤집어서 확인** 후, **직접 뒤집기**에서 버튼으로 목표 모양 3개 만들기 |

각 메뉴 끝에 「알게 된 점」 정리 화면이 나옵니다.

### B. 도형의 이동 도전하기

우봉고 퍼즐 5판 · 한 판 1분. 판을 모두 채우면 성공입니다.

- 시간 안에 못 채우면 정답이 바로 나오지 않고 **다시 도전**과 **정답 보기** 중에서 고릅니다.
- 5판을 모두 도전하면 체험 확인증 화면이 나옵니다(캡처해서 간직). 마친 알아보기 메뉴도 함께 적힙니다.

## 조작 (체험관 교구와 같음)

| 버튼 | 도전하기에서 하는 일 |
|---|---|
| ▲▼◀▶ | 밀기: 조각 한 칸씩 옮기기 (꾹 누르면 계속) |
| A | 판·조각 고르기 (놓은 조각도 다시 골라 고치기) |
| B | 돌리기: 시계 방향 90° |
| C | 뒤집기: 오른쪽으로 뒤집기 |
| D | 놓기 · 다음 단계 |

알아보기 화면에서는 A·B·C·D 버튼의 역할이 화면마다 바뀌며, 버튼 아래에 지금 하는 일이 표시됩니다. 화면의 카드를 손가락으로 눌러도 됩니다. 왼쪽 위 **⌂ 처음** 버튼으로 언제든 첫 화면으로 돌아갑니다.

## 선생님이 고치는 곳 (index.html 아래쪽 script 맨 위)

- `TIME` 도전하기 한 판 제한 시간(초)
- `PLACE` 확인증에 나오는 기관 이름
- `PUZ` 도전하기 게임판 5개 — 글자 하나가 조각 하나, `.` 은 빈칸
- `PIECES` 알아보기에서 쓰는 조각 3개 (돌리거나 뒤집으면 모양이 달라 보이는 조각을 쓰세요)
