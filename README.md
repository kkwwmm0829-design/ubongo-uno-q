# 평면 우봉고 — 휴대폰 버전

조이스틱 없이 휴대폰 화면 버튼으로 하는 평면 우봉고입니다. (경남수학문화관 체험탐구관 · 초등 4학년)

- `index.html` 한 파일로 동작합니다. 휴대폰·태블릿·컴퓨터 브라우저에서 열면 됩니다.
- `평면우봉고_휴대폰_QR.png` : 게임 주소(https://claude.ai/artifact/W3Hhgd3UmFtWB3imtEWsQG)로 연결되는 QR코드

## 조작 (체험관 교구와 같음)
| 버튼 | 하는 일 |
|---|---|
| A | 판·조각 고르기 (놓은 조각도 다시 골라 고치기) |
| B | 시계방향 90° 돌리기 |
| C | 뒤집기 |
| D | 놓기 · 다음 단계 |
| ▲▼◀▶ | 조각 한 칸씩 옮기기 (꾹 누르면 계속) |

판 카드나 조각 상자의 조각을 손가락으로 눌러서 고를 수도 있습니다.
5문제 · 한 판 1분 · 마지막에 체험 확인증 화면(캡처해서 간직).

## 선생님이 고치는 곳 (index.html 아래쪽 script 맨 위)
- `TIME` 한 판 제한 시간(초)
- `PLACE` 확인증에 나오는 기관 이름
- `PUZ` 게임판 5개 — 글자 하나가 조각 하나, `.` 은 빈칸
